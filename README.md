# Lung Cancer Detection from Chest CT Images

Lung Cancer Detection using Morphological Image Processing Techniques

This project is part of the **Introduction to Image Processing** course.  
The goal is to build a **custom CNN model (no transfer learning)** to classify chest CT images into four classes:

- Adenocarcinoma  
- Large cell carcinoma  
- Squamous cell carcinoma  
- Normal

Classical image processing techniques (e.g. filtering, contrast enhancement) will also be used as preprocessing and compared with the CNN-only baseline.

---

## 📂 Dataset

- **Source**: Kaggle – *Chest CT-Scan images Dataset*  
- **Link**: https://www.kaggle.com/datasets/mohamedhanyyy/chest-ctscan-images
